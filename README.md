# Simple Weather App

Basit bir statik hava durumu uygulaması. `index.html` dosyasını tarayıcıda açarak çalıştırabilirsiniz.

## Dosyalar
- index.html
- style.css
- script.js

## Çalıştırma
1. Projeyi indirin veya klonlayın
2. `index.html` dosyasını tarayıcıda açın
3. Şehir ismi girin ve "Get Weather" butonuna tıklayın
